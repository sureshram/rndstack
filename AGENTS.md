# Agent instructions

## General Principles

- Always write clear, concise, easy-to-follow and less verbose.
- You must use simple english for non-technical words
- Prefer visual representation for explainability vs prose
- Use tables and graphs for data representations
- Use bullet lists for key points
- Write illustative diagrams to express ideas



## Design Principles


- Use ubiquitous Language across the project both in code and documentation
- Apply Domain Driven Principles like Bounded Context where large domain models by dividing them into different Bounded Contexts and being explicit about their interrelationships
- Apply Domain Driven Principles like classifying objects into Entities, Value Objects, and Service Objects


## Writing Guidance

- When write specifications, documentations, use ASD-STE100 controlled language specification
- produce clear, well-structured, detailed text on complex topic


## Testing

- Always write end-to-end tests


## Logging

- When building software programs, add logging appropriate to the coding language
